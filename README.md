# Random Task Generator

**Автор:** [Ваше Имя Фамилия]

## Описание

Графическое приложение для генерации случайных задач. Помогает выбрать занятие для учёбы, спорта или работы. История задач сохраняется в файл и отображается в интерфейсе.

## Возможности

-   **Генерация задачи:** Кнопка выбирает случайное занятие из предустановленного списка.
-   **Фильтрация:** Можно выбрать категорию (Учёба, Спорт, Работа) или показать все задачи.
-   **История:** Все сгенерированные задачи сохраняются в список и записываются в файл `tasks.json`.
-   **Добавление задач:** Возможность добавить свою задачу с проверкой на пустой ввод.
-   **Контроль версий:** Проект управляется через Git.

## Инструкция по запуску

1.  Установите Python 3.x.
2.  Убедитесь, что установлены стандартные библиотеки (`tkinter` входит в поставку Python).
3.  Запустите файл `main.py`.
4.  Нажмите кнопку «Сгенерировать задачу».
5.  Для добавления своей задачи нажмите «Добавить свою задачу».
6.  Используйте фильтр для выбора категории.

## Примеры использования (тесты)

1.  **Тест генерации:** Нажмите кнопку несколько раз. Текст в верхней части окна должен меняться на случайный элемент из списка.
2.  **Тест фильтрации:** Выберите фильтр «Спорт» и нажмите кнопку. Сгенерированная задача должна относиться только к спорту.
3.  **Тест истории:** После генерации нескольких задач прокрутите список внизу — там должны появиться все ранее выбранные пункты.
4.  **Тест сохранения:** Закройте программу и запустите снова. История задач должна загрузиться из файла и отобразиться в списке.
5.  **Тест проверки ввода:** Нажмите «Добавить свою задачу» и попробуйте нажать «ОК», не вводя текст. Должно появиться окно с ошибкой «Задача не может быть пустой!».
